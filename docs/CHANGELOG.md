# 版本试错沿革

| 版本 | 主要变化与观察 |
| --- | --- |
| v1–v6 | 从小型Mac桥接探针到游戏启动壳，处理资源路径、退出日志、完整父子扩展及签名，完整资源导入后进入游戏 |
| v7–v8 | 初始触控界面出现，但事件选择器导致输入失效 |
| v9 | 修正触控跟踪选择器，空格启动提示及双摇杆首次可用，手感未通过 |
| v10 | 尝试调整摇杆数学，用户仍拒绝手感 |
| v11 | 换成完整塞尔达式单画布与布局编辑器，移除直接触屏鼠标，编辑器可用但操作仍滞后/归零 |
| v12 | 修正误清空触摸路径，持续按住归零改善，滞后仍在 |
| v13 | 有界UIKit事件服务、脏UI提交、计时边界拆分，用户确认圆点跟手及短按正常 |
| v14 | 加入默认常开的iPad体感，收到方向幅度不一致和不流畅反馈 |
| v15 | 正交体感轴、严格校准、时间滤波、独立横纵倍率，代码检查通过，完整手感验收待补 |
| v16 | 正式名称和原包图标转换，单模式改为1920×1324并记录实际drawable |
| v17/v17b | 菜单扩成三档再四档，用户反馈可用 |
| v18 | EDR能力桥接到UIScreen，日志确认potential16、current1.20，但无法据创建快照判断最终状态 |
| v19 | 实际出帧诊断确认仍为8位sRGB SDR，降低亮度的对照未触发HDR |
| v20 | 宿主先申请EDR，但游戏实际出帧仍回到SDR，27次采样失败，假设被否定 |
| v21 | 追踪并兼容HDR枚举中的旧Mac Metal功能集查询，39次出帧采样确认EDR、RGBA16Float、PQ，用户反馈成功 |

保留最终v21源码与模块，前期失败版本的完整游戏包在私有工作区中管理。公开文档保留失败原因与验证边界，避免把编译、签名、安装和运行混为一次验收。
