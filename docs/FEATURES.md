# 功能说明

## 触控手柄

提供双摇杆、方向键、动作键和 K1/K2 自定义快捷键。左右手指分别保持控制权，允许同时移动、转镜头和按动作键。已改善触点误归零、短按漏识别及界面更新滞后。

布局编辑支持位置、大小、透明度、固定/浮动摇杆，以及保存、取消和恢复默认。可隐藏虚拟手柄。当前以虚拟手柄操作为主，未提供触屏鼠标模式。

## 体感视角

使用 iPad 的 Core Motion，将设备转动映射到游戏右摇杆。支持常开/瞄准、重新校准、方向反转、灵敏度和横纵独立倍率。触屏右摇杆操作优先；不同设置下的方向一致性仍需实际调节和验证。

## 显示与超分

针对 11 英寸 M5 iPad Pro 的 2420×1668 屏幕提供四个输出档位：

| 输出尺寸 | 用途 |
| --- | --- |
| 1210×834 | 较低输出负担 |
| 1815×1251 | 兼顾清晰度与负担，也是本次 HDR 已确认的实际输出尺寸 |
| 1920×1324 | 宽度达到 1920，保持 iPad 屏幕比例 |
| 2420×1668 | 屏幕原生输出尺寸，负担更高 |

游戏原有 MetalFX Temporal 可将较低内部渲染分辨率重建为较高输出分辨率。分辨率、超分质量档和帧率需结合场景选择；最高输出档位不代表所有画面均以该分辨率原生渲染。

## HDR 输出兼容

适配指定 Mac 2.5.0 宿主的 HDR 能力查询，使游戏使用其原有 HDR 渲染路径。已在实测设备确认 EDR、RGBA16Float 和 PQ 输出。此适配受执行文件版本约束，不适用于任意更新版本。

## 分体资源与更新

游戏资源位于 App 的 Documents/GameData，兼容模块包含在程序包内。保持同一应用标识覆盖更新，可保留原有资源、存档和偏好。主屏名称为「赛博朋克 2077」，图标沿用使用者自己的原始游戏包。
