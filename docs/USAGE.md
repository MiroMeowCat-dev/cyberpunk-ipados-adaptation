# 安装与使用

## 1. 准备材料

- 你有权使用的《赛博朋克 2077》Mac 2.5.0 游戏文件。
- 已转换为 iPadOS、使用 Documents/GameData 资源布局的无签名 IPA。主程序哈希必须与 `update-kit-v21/manifest.json` 一致。
- 可用的 iPad USB 数据连接、开发者模式和个人开发签名环境。
- Python 3.11 或更新版本，用于运行本仓库的离线工具。
- 足够的存储空间：该版本完整游戏资源约 79.7GB，另需程序和导入时的临时空间。

本仓库的更新工具从兼容 IPA 开始工作。它不会从任意 Mac 原包直接生成 iPad 游戏，也不附带资源或签名身份。

## 2. 生成更新包

下载仓库，在仓库目录执行以下命令。示例路径需要换成自己的文件位置；输入和输出均应放在仓库以外。

```powershell
python tools/verify_archive.py
python tools/apply_update.py --input "../private-input/compatible-unsigned.ipa" --output "../private-output/cyberpunk-v21-unsigned.ipa"
```

工具检查宿主和模块哈希，保留游戏内容及原有应用标识，更新两份兼容模块、父子包版本和 HDR 兼容配置。原输入不会被覆盖。若报宿主不匹配，请检查游戏和基础转换版本，不要绕过校验。

## 3. 签名和安装

该宿主包含 `Extensions/Downloader.appex`。签名工具必须支持此目录，为主 App 和子扩展分别配置真实的描述文件、共享组及签名，并保留所需内存权限。

本仓库提供基于 iLoader 2.4.1 的扩展感知签名源码，见[签名组件说明](SIGNING_SOURCE.md)。原版工具若不处理这些扩展，不能直接替代。仓库没有预编译签名 EXE。

用自己的开发身份签名生成的 IPA，检查父子包与权限后，再通过支持该包结构的安装工具安装。签名和安装是两个步骤：前者生成有效签名，后者将已签名应用传入设备。账号、密码和验证码由你在签名工具中输入。

首次打开前按系统提示启用开发者模式，并在「设置 → 通用 → VPN 与设备管理」中信任自己的开发者身份。签名到期后需续签，实际期限和安装数量以所用描述文件及 Apple 返回为准。

## 4. 首次导入资源

将自己的 Mac 包 `Contents/Data/` 内文件，按原有相对目录结构放到此 App 的 `Documents/GameData/`。例如：

```text
Documents/
  GameData/
    archive/
      Mac/
        content/
          ...
```

不要额外套入 `Contents/Data` 两层目录。导入时关闭游戏；可通过支持应用文件共享的工具复制到应用 Documents，或先在「文件」中准备 GameData 文件夹再导入。此宿主已启用文件共享。大量资源建议分批复制，并核对数量、大小与自己的源文件。

**覆盖更新时不需要重新导入整套资源**，前提是应用标识和原容器保持不变。

## 5. 操作和设置

- 左摇杆移动，右摇杆转视角，动作键按游戏中的手柄提示使用。
- 底部「设置」可调整虚拟手柄、K1/K2、布局与体感。进入布局编辑后可拖动按键、调大小和透明度，并保存或取消。
- 需要键盘按键的启动提示，可将 K1/K2 指定为对应按键，例如空格。
- 体感可常开或按瞄准场景启用；先校准，再调整横纵灵敏度。体验仍受游戏右摇杆死区和响应曲线影响。
- 在游戏的视频设置中选择分辨率和超分档位。输出分辨率不等于内部 3D 渲染分辨率；切换后的效果以实际画面和显示信息为准。

## 6. 后续更新

先保存游戏、彻底退出并备份存档和偏好，再对新包签名，以**同一账号、同一应用标识**覆盖安装。不要先卸载旧 App。保留自己的无签名 IPA、资源来源及存档备份，公开仓库不能代替这些文件。
