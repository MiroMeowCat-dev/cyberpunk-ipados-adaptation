# iPad 专项改进

## 触控

一个UIView持有手指到按钮/左右摇杆的所有权映射，手指跨中线不会自动转交摇杆。按键状态以多来源位集合并，避免K1/K2或别的手指释放同一个动作。右摇杆被手指占用时优先于体感，包括手指停在中心。

布局编辑器统一处理位置、大小、透明度、固定/浮动、保存/取消和恢复默认。真实后台、取消和物理手柄接管释放输入。安全区重复通知与未变化的手柄通知保留当前手指。

v13在游戏现有轮询处保留原截止/事件队列行为，有界服务UIKit就绪事件，并在控件变脏时提交绘制。源码中的诊断分别测入口年龄、发布成本、回调时长和draw序号。

## 体感

Core Motion读取最新设备角速度，按横屏方向换轴。yaw轴与pitch正交，过滤过期和非法样本。常开是用户选择的默认值，支持仅瞄准、校准、反转、灵敏度和横纵幅度。体感经虚拟右摇杆进入游戏，因此游戏的死区和响应曲线仍会影响体验。

## 显示模式

CoreGraphics兼容层向游戏报告四个不同模式，逻辑模式尺寸与该模式像素尺寸一致。物理面板保持其原生尺寸语义。11英寸M5上的计算结果为1210×834、1815×1251、1920×1324、2420×1668，1920×1324为中间推荐目标。

游戏原有MetalFX Temporal路径继续运行。内部渲染尺寸与超分输出尺寸通过HUD区分，刷新率与实际帧数也分别记录。当前没有完成Apple或AMD插帧的逐项实机验收。

## HDR兼容

NSScreen的current/potential EDR查询映射到UIScreen相应查询。游戏HDR枚举还使用旧Mac Metal功能集10001，v21仅在经过校验的2.5.0执行文件查询返回位置上做兼容。条件包含原生Metal4和Apple9支持、RGBA16Float纹理创建通过、调用者为主游戏且返回偏移符合固定值。

主程序hash与偏移在update-kit清单中保存。游戏自行完成HDR分支中的16位浮点纹理和PQ色彩空间配置。v21无需持续强制图层开关。实际出帧39次采样已确认开启。该桥接具有明确版本边界，其他Mac游戏或更新版本需要另行检查。

## 名称、图标与更新

主屏名称为赛博朋克2077。本机图标从用户自己的Mac包AppIcon.icns转换成iPad所需尺寸，公开档案没有分发该游戏图标。最终更新模块只替换两份兼容库，并更新父子包版本及私有HDR查询配置，应用身份、资源与用户存档通过覆盖安装保留。
