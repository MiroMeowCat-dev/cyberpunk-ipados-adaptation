# 验收范围

实测设备为11英寸iPad Pro M5、12GB内存、512GB存储、iPadOS27.0.1，面板2420×1668、最高120Hz。当前归档build为2026111103。

| 项目 | 结论与证据 |
| --- | --- |
| 真实游戏 | 用户已进入场景并通过摇杆移动、转视角 |
| v13输入 | 用户确认圆点跟手与短按正常，日志支持输入链路已工作 |
| 布局编辑 | 用户确认可打开并拖动，重启持久化等仍需独立验收 |
| 四档分辨率 | 枚举代码与用户反馈通过，HDR测试实际输出1815×1251，全部四档的HUD对照尚未完成 |
| MetalFX Temporal | 曾观测786×542 → 1210×834的运行HUD，适用于当时配置 |
| HDR能力 | v21原生旧Mac查询返回0，限定兼容结果1，实际现代GPU/浮点目标检查通过 |
| HDR出帧 | 39次采样全部wants=1、format115/RGBA16Float、ITUR2100PQ |
| v15体感 | 数学、采样和校准回归检查通过，用户报告过的方向一致性仍待复测 |
| Xbox手柄 | 原生映射设计，用户设备当时无法连接，尚未实测 |
| 插帧 | 未完成MetalFX/FSR逐项开关、生成帧和画面正确性验证 |
| 色彩与稳定性 | 未进行仪器亮度/色彩校准、长期热机和全场景验收 |

离线检查包括1797项强导入闭合（强弱缺失均0）、ZIP CRC、16个Mach-O的合成签名/篡改拒绝检查，以及输入、布局、体感和模式范围检查。合成证书不是Apple开发者身份，设备的安装验证另行执行。

本仓库提供的兼容模块是实测版本的无个人签名副本。重编译、修改、不同宿主或SDK均需重新真机验证。HDR信号路径已启用的结论不能替代峰值亮度和色彩准确度测量，也不能推出固定60帧或其他机型兼容性。

原始诊断、设备标识、profile、私有检查点和用户存档保存在本地。公开证据由白名单字段重建，见verification/device-acceptance.json。
