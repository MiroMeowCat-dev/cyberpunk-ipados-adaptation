# 兼容范围与限制

## 已实测配置

| 项目 | 配置 |
| --- | --- |
| 设备 | 11 英寸 iPad Pro M5 |
| 内存 / 存储 | 12GB / 512GB |
| 系统 | iPadOS 27.0.1 |
| 面板 | 2420×1668，最高 120Hz |
| 游戏输入 | Mac 2.5.0，已转换的 Documents/GameData 型宿主 |
| 适配版本 | v21 / 2026111103 |

已确认能进入游戏场景，触控双摇杆、动作短按和布局编辑可用；分辨率菜单已生效，HDR 输出路径已确认。此次 HDR 实测输出为 1815×1251。

## 使用边界

- 更新工具按清单固定主程序哈希校验。不同发行包、游戏更新版或基础转换结果可能不匹配，需另行适配。
- 程序声明的最低系统是 iPadOS 26.0，但这不是已验证系统范围；当前实际运行验证仅覆盖 iPadOS 27.0.1。
- 当前包面向 iPad。其他 iPad 型号、13 英寸版本和 iPhone 未验证，不能只按芯片名称判断兼容性。
- 四个分辨率档位均已提供，但尚未逐档完成相同场景下的画质和性能比较。
- MetalFX Temporal 有运行证据；Apple/AMD 插帧尚未完成独立验证，不承诺开启后达到固定 60 帧。
- 体感不同方向的一致性、布局重启后的所有组合、Xbox 实体手柄及长时间热机稳定性仍待进一步验证。
- HDR 输出链路已确认，峰值亮度和色彩准确度未经仪器校准。
- 签名、内存权限和应用容器身份必须正确；个人签名仍可能到期，需要重新签名。

本项目使用兼容层在 iPad 本地运行指定 Mac 游戏代码，不是在 iPad 上安装完整 macOS。当前成果不等于其他 Mac 游戏也能直接运行。
