# 赛博朋克 2077 · iPadOS 适配

让兼容的《赛博朋克 2077》Mac 2.5.0 宿主在 iPad 上本地运行，并加入触控手柄、可编辑布局、体感、适合 iPad 比例的分辨率选项和 HDR 输出兼容。

当前版本：**v21 / 2026111103**。实测设备：**11 英寸 iPad Pro M5 · 12GB 内存 · iPadOS 27.0.1**。

## 能带来什么

| 功能 | 使用效果 |
| --- | --- |
| 虚拟手柄 | 双摇杆、方向键、动作键，以及 K1/K2 自定义快捷键 |
| 布局编辑 | 拖动按键，调整大小和透明度，切换固定/浮动摇杆，保存或恢复默认布局 |
| 输入设置 | 显示/隐藏虚拟手柄，集中调整触控与体感设置 |
| iPad 体感 | 转动设备控制视角；支持常开/瞄准、校准、反转和横纵灵敏度 |
| 四档显示模式 | 1210×834、1815×1251、1920×1324、2420×1668，保持 11 英寸 M5 屏幕比例 |
| MetalFX | 沿用游戏的 MetalFX Temporal 超分路径，内部渲染分辨率与输出分辨率分别设置 |
| HDR 兼容 | 为指定宿主启用 HDR 输出路径；实测为 16 位浮点、PQ 色彩空间 |
| 分体更新 | 游戏资源与程序分开保存，同标识覆盖更新，避免重复导入整套资源 |

## 使用前先看

- 本仓库提供**适配源码、兼容模块和更新工具**，不提供游戏、完整 IPA、图标、Apple SDK 或个人签名资料。
- 更新工具需要你自己的、已经完成基础转换的 **Mac 2.5.0 / Documents/GameData 型无签名 IPA**。输入主程序必须与清单哈希一致。
- 从原始 Mac `.app` 开始的基础转换，仍需按上游 [macos-on-ios](https://github.com/zorrobyte/macos-on-ios-public) 流程准备；本仓库不是通用的一键转换器。
- 当前只在上述 11 英寸 M5 iPad Pro 上完成运行验证。其他机型、iPhone、其他游戏版本不属于已验证范围。

## 开始使用

1. 阅读[安装与使用](docs/USAGE.md)，准备兼容宿主、自己的游戏资源和签名环境。
2. 校验仓库文件，将兼容模块应用到无签名 IPA。
3. 使用支持父子扩展独立签名的工具签名并安装，首次再导入游戏资源。
4. 打开游戏，使用底部「设置」配置手柄、布局和体感，在游戏设置中选择显示模式。

已有本适配版本的用户：保存并退出游戏，备份存档后，以同一应用标识覆盖更新。**不要先卸载旧 App**，其容器中保存着资源和存档。
